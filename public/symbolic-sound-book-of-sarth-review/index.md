# Symbolic Sound – Book of Sarth Review

[Symbolic Sound](https://news.symbolicsound.com/2012/11/the-book-of-sarth/) did a wonderful review of The Book of Sarth. Full of thoughtful description and analysis, they reference the meta-narrative : “an ear worm about and ear worm” … I think Alex would be pleased.

I am glad to get this shout out from SSC because Kyma was so central to the sound and feel of The Book of Sarth, especially Primary Deforestation [vocal processing] and If I Can [pulse code cello played on continuum fingerboard].
